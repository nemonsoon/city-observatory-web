## 1. 概要

### 1.1 コンセプト

都市の"いま"を観測するダッシュボード。日本の主要都市の天気と大気質を1画面で可視化する Web アプリケーション。

### 1.2 対象地域と前提

| 項目         | 内容                                                    |
| ------------ | ------------------------------------------------------- |
| 対象地域     | 日本の主要6都市（東京・大阪・名古屋・札幌・福岡・那覇） |
| 言語・単位   | 日本語 UI、メートル法（℃、m/s、mm、µg/m³）              |
| タイムゾーン | `Asia/Tokyo`                                            |
| 既定都市     | 東京                                                    |

### 1.3 制約条件

- フロントエンドだけで完結する。バックエンドを持たない
- 非商用。利用している外部 API の規約に合わせる
- Vercel の無料枠でデプロイする
- 認証不要の無料 API を優先して使う

## 2. 想定する利用者

外出前や外出中に、行き先の天気と空気の状態をまとめて確かめたい人。

天気アプリと大気質アプリを行き来せずに済むこと、6都市を切り替えて比べられることが、このサービスの提供価値にあたる。

## 3. 機能要件

### 3.1 実装済み

#### F1. 都市の切り替え

- 固定6都市のボタンによる切り替え
- 既定は東京

#### F2. 地図の表示

- MapLibre GL JS による地図（ズーム・移動が可能）
- 観測地点のマーカー表示と、中心座標への移動
- 降水レイヤーの重ね合わせ切り替え
- 配色に追従した地図スタイルの切り替え
- OpenStreetMap と MapTiler のクレジット表記

#### F3. 天気の表示

- 現在の気温・体感温度・湿度・降水確率・風速・風向
- 24時間の気温の推移グラフ
- 天気コードによるアイコンとラベル（WMO 準拠）
- UV 指数と、その段階のラベル
- 日の出から日の入りまでの経過表示

#### F4. 大気質の表示

- PM2.5 濃度の表示
- PM2.5 にもとづく4段階のラベル（良好・普通・悪い・危険）
- 24時間の PM2.5 の推移グラフ

#### F5. 2都市の比較

- 2都市の観測値を並べた表
- 右の都市から左の都市を引いた差の列

#### F6. 派生指標

- 快適度スコア（気温・湿度・風速・降水確率・PM2.5 から算出）
- 外出リスクの3段階判定

### 3.2 UX

- 読み込み中のスケルトン表示
- 取得に失敗したときのフォールバック表示
- 明るい配色と暗い配色の切り替え（端末の設定にも追従）
- 読み込み時に上から順に記入されていく演出

キャッシュの設定は [技術仕様書](technical-specifications.md#24-キャッシュ戦略) にある。

## 4. 非機能要件

### 4.1 パフォーマンス

- Lighthouse の Performance スコア 90 以上
- FCP 1.5 秒未満、LCP 2.5 秒未満、CLS 0.1 未満

### 4.2 互換性

- Chrome・Firefox・Safari・Edge の最新版
- 携帯・タブレット・デスクトップの各画面幅
- 明るい配色と暗い配色の両方

### 4.3 品質

- TypeScript の strict モード
- Zod による実行時バリデーション
- UI・Model・Domain の責務分離（Feature-Sliced Design）
- ESLint・Prettier を Husky と lint-staged で自動実行
- Vitest による純粋関数のテスト
- Playwright による画面の確認

コードの書き方の約束事は [コーディング規約](coding-guidelines.md) にある。

## 5. 画面構成

### 画面 A: 観測（`app/page.tsx`）

選択した1都市の観測値・グラフ・地図を1画面に収める。

観測地点と現在時刻、気温、5つの観測値（UV 指数・快適度・外出リスク・風速・PM2.5）、日照の経過、24時間の推移グラフと地図、の順に罫線で区切って並べる。

グラフと地図はデスクトップで横並び、携帯で縦積みになる。

### 画面 B: 比較（`app/compare/page.tsx`）

2都市の観測値を表で並べ、差の列を添える。24時間の推移グラフを都市ごとに表示し、最後に2都市の位置関係を地図で示す。

## 6. 外部 API

Open-Meteo（天気予報・大気質予報）、MapTiler（地図タイル）、OpenWeatherMap（降水タイル）を使う。

エンドポイント・パラメータ・レート制限・利用規約は [API 仕様書](api-specifications.md) にある。
